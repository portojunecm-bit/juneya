# Portofolio

Template portofolio statis (HTML + CSS), tanpa framework dan tanpa build.

## Cara mengedit

1. Buka `index.html`, ganti semua teks placeholder:
   - `Nama Anda`, `NamaAnda`
   - Bagian Tentang, Proyek, Keahlian, Kontak
   - Tautan GitHub, LinkedIn, dan email
2. Ubah warna di bagian `:root` pada `style.css`.

## Cara publikasi di GitHub Pages

1. Buat repository baru di GitHub bernama `username.github.io`
   (ganti `username` dengan nama pengguna GitHub Anda). Atur sebagai Public.
2. Klik **Add file → Upload files**, unggah `index.html`, `style.css`, dan `README.md`, lalu **Commit changes**.
3. Buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1–2 menit, situs aktif di `https://username.github.io`.

## Mengedit setelah online

Buka file di GitHub, klik ikon pensil (Edit), ubah isinya, lalu **Commit changes**. Situs akan diperbarui otomatis.
